# NEXUS

An intelligent, agent-powered project management platform.

## Branch and Pull Request Rules
- main is protected: no direct pushes are allowed. All changes must go through Pull Requests (PRs).
- Branch names should clearly describe the work being done.
- Keep PRs small and require a review from another team member before merging.
- Definition of Done (DoD): All tests pass, the UI is properly connected, and .env.example is up to date.
